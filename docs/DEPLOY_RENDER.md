# Deploying StockLens to Render (step by step)

This puts the StockLens backend on the internet with a permanent HTTPS
address, so the mobile app works anywhere (any Wi-Fi or mobile data) with
your laptop switched off.

**What gets created** (all defined in `render.yaml`):

| Item | What it is | Plan | Approx. cost |
|---|---|---|---|
| `stocklens-db` | PostgreSQL database: users, rankings, watchlists, notifications | Basic 256 MB | ~$6 / month |
| `stocklens-api` | The StockLens API at `https://stocklens-api.onrender.com` | Starter | $7 / month |
| `stocklens-ranking`, `stocklens-notifications`, `stocklens-outcomes` | Scheduled jobs: daily ranking after market close, notifications, outcome tracking | Starter cron | ~$1–3 / month total |

Region: Singapore (closest to India). Prices are Render's list prices; check
the summary Render shows before you confirm.

## Free plan for testing (`deploy/render-free/render.yaml`)

To try StockLens in the cloud at no cost, use the free Blueprint instead.
It creates only a free database and a free web service.

**Free-plan limits (Render's rules):**

| Limit | What it means for you |
|---|---|
| The server sleeps after ~15 minutes without use | The first request after a pause takes ~30–60 s. The app may show "Could not reach the StockLens server" once; tap **Retry** |
| Free database expires 30 days after creation, no backups | Fine for testing. Upgrade the database plan before day 30 if you want to keep the data |
| No scheduled jobs | No automatic daily ranking or daily summaries. Start analysis runs from the admin console (Step F4) |
| 512 MB memory | The informational ML signal is switched off (it has weight 0 in the score) and the engine uses 2 threads. Measured peak for a full 299-stock run: ~370 MB |
| No Shell access | Admin account and data copy are done from your laptop (below) |

**Steps:**

- **F1.** Do Step 1 below (account; a card is not required for free services).
- **F2.** **New +** → **Blueprint** → select `stock-prediction-app` → **Connect**.
  In **Blueprint Path**, type `deploy/render-free/render.yaml`. Name `stocklens` → **Apply**.
- **F3.** Wait for the deploy (5–15 min), then open
  `https://stocklens-api.onrender.com/api/v1/health`.
- **F4.** **Data and admin account (from your laptop):**
  - Copy your data with **Step 3** below (it creates your existing accounts
    in the cloud too), **or**
  - Start fresh: register in the app, then make your account an admin. Copy
    the database's **External Database URL** (dashboard → stocklens-db →
    **Connect**) and run in PowerShell in the project folder:
    ```powershell
    $env:DATABASE_URL = "<External Database URL>"
    venv\Scripts\python.exe -m scripts.seed_admin your-email@example.com
    Remove-Item Env:DATABASE_URL
    ```
- **F5.** Run the first analysis with **Step 5** below. Keep the admin
  console's Engine Runs page open and refresh it until the run completes:
  a free server sleeps when nobody uses it, which would stop a run midway.

**Moving to the paid setup later:** create a new Blueprint from `render.yaml`
(paid plans, scheduled jobs). Copy the data across, and delete the free
services afterwards. The app address stays the same if you reuse the name
`stocklens-api` after deleting the free one.

## Step 1: Create your Render account (once)

1. Open **https://render.com** and click **Get Started**.
2. Choose **GitHub** and sign in with the GitHub account that owns
   `stock-prediction-app` (Himanshu11007).
3. When GitHub asks which repositories Render may access, choose
   **Only select repositories** → `stock-prediction-app` → **Install**.
4. In Render: your avatar (top right) → **Billing** → add a payment card.

## Step 2: Create everything from the Blueprint

1. In the Render dashboard click **New +** → **Blueprint**.
2. Select the `stock-prediction-app` repository → **Connect**.
3. Blueprint name: `stocklens`. Render lists the database, the web service
   and the 3 cron jobs from `render.yaml`.
4. Click **Apply**.

Render now builds and starts everything (5–15 minutes the first time). The
database schema is created automatically (`alembic upgrade head` runs before
the API starts). You do not enter any passwords or secrets; the security
key is generated by Render.

**Check it works:** open
`https://stocklens-api.onrender.com/api/v1/health` in your browser. You
should see `{"status":"ok","app":"StockLens API",...}`.

> If Render shows a different address for `stocklens-api` (the name was
> taken), use that address everywhere below and tell your developer. The
> mobile app and `CORS_ALLOWED_ORIGINS` must use the same address.

## Step 3: Copy your existing data (optional, recommended)

This copies your current users, watchlists, stock master and analysis from
the laptop database (`storage/app.db`) into the new cloud database.

1. Render dashboard → **stocklens-db** → **Connect** → copy the
   **External Database URL**. Treat it like a password: don't paste it into
   chats or files.
2. Open PowerShell in `C:\Python\Git\stock-prediction-app` and run:
   ```powershell
   $env:TARGET_DATABASE_URL = "<paste the External Database URL here>"
   venv\Scripts\python.exe scripts\migrate_sqlite_to_postgres.py --source storage\app.db
   Remove-Item Env:TARGET_DATABASE_URL
   ```
3. It prints each table with its row count and ends with
   `Copied ... rows ...; counts verified.`

The script never modifies your laptop database. It refuses to run if the
cloud database already has users (so it can't overwrite cloud data).

**If it can't connect** (a company network may block database port 5432),
skip this step: the cloud starts empty, you register again in the app and
create the admin account with Step 4. Rankings are rebuilt by the first
ranking run.

## Step 4: Admin account (only if you skipped Step 3)

Render dashboard → **stocklens-api** → **Shell**, then run:
```bash
python -m scripts.seed_admin your-email@example.com
```
It asks for a password (hidden input). Use this account in the admin console.

## Step 5: First analysis run

The ranking job runs automatically every trading day after 16:00 IST. To
run one now, use the admin console from your laptop against the cloud API:
```powershell
$env:STOCKAI_API_URL = "https://stocklens-api.onrender.com/api/v1"
venv\Scripts\streamlit.exe run admin_console\app.py
```
Sign in as an admin → **Engine Runs** → **Start run**. Also add the year's
NSE holidays under **Application Configuration** → `market.holidays`.

## Step 6: Install the cloud version of the app

Your developer builds an APK pointed at `https://stocklens-api.onrender.com`.
Install it on your phone. It works on any network; the laptop is no longer
needed.

## Day-to-day

- **Updates:** every push to the `main` branch redeploys automatically
  (schema migrations run first; if they fail, the old version keeps running).
- **Logs:** Render dashboard → service → **Logs**. Cron job history:
  each cron service → **Events / Logs**.
- **Backups:** the paid PostgreSQL plan includes daily backups
  (dashboard → stocklens-db → **Recovery**).
- **Optional settings** (dashboard → stocklens-api → **Environment**):
  push credentials (`FCM_*`, `APNS_*`, docs/NOTIFICATIONS.md), email OTP
  (`OTP_SMTP_*`, docs/AUTHENTICATION.md). Add the same `FCM_*`/`APNS_*`
  variables to `stocklens-ranking` and `stocklens-notifications` so jobs can
  push too.
- **Market data:** prices and fundamentals come from Yahoo Finance. Cloud
  servers are occasionally rate-limited; a run then reports data errors and
  the next scheduled run retries. Nothing is ever filled with invented values.
